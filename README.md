# aipass-bridge (repo)

Two unrelated things share this directory:

- **[`aipass-bridge/`](./aipass-bridge/)** — the actual project. A zero-dependency
  Node bridge plus a Chrome MV3 extension that let a terminal talk to
  `de.aipass.net`'s chat, with streaming, through an already-logged-in browser
  tab. Start here:
  - [`aipass-bridge/README.md`](./aipass-bridge/README.md) — setup and usage
  - [`aipass-bridge/DOCS.md`](./aipass-bridge/DOCS.md) — architecture and internals
- **Root Next.js app** (`app/`, `next.config.ts`) — a near-untouched
  `create-next-app` bootstrap. `AGENTS.md` is auto-generated by `next dev`.

`aipass-bridge/` imports only `node:*` builtins — no `npm install` needed to run
the bridge, the CLIs, or the tests. `npm install` is only for the Next.js app.

## Commands

| | |
|---|---|
| `npm run dev` | start the **bridge** on `:8787` |
| `npm test` | the bridge/CLI test suite (`node --test aipass-bridge/test/*.test.mjs`) |
| `npm run chat` / `npm run agent` / `npm run models` / `npm run conversations` | the CLIs (see `aipass-bridge/README.md`) |
| `npm run dev:next` | start the Next.js app on `:3000` |
| `npm run build` / `start` / `lint` | the Next.js app |

## The Next.js part

`npm install`, then `npm run dev:next` and open
[http://localhost:3000](http://localhost:3000). It's a stock
[`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app)
bootstrap — edit `app/page.tsx`. Read `AGENTS.md` before changing code under
`app/`: this Next.js version has breaking API changes and points at the guides
in `node_modules/next/dist/docs/`.
